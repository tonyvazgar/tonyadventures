# TonyAdventures — Landing

1. Datos y textos (WhatsApp, Instagram, precios, fechas, fotos): `src/app/data.ts`.
2. Fotos: ponlas en `public/fotos/` y agrégalas a `PHOTOS` en `data.ts`.
3. Cada sección es un componente en `src/app/<seccion>/`. El orden se define en `src/app/app.component.ts`.
4. Local: `npm install && npm start`
5. Deploy: sube a GitHub (rama `main`) → Settings → Pages → Source: **GitHub Actions**.
